# One Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the public site one header, nav, footer, logo and gold palette, move `/` to the Worker, and add a `/tools` index page.

**Architecture:** A plain-data module, `shared/site.js`, holds the nav items, CTA label, footer copy and colors. The Worker's `layout()` (`worker/pages.js`) and the React `Nav`/`Footer` both render from it, and node tests check that both sides stay wired to it. The home page and the tools index become Worker-rendered string pages, served first by the Worker through `run_worker_first`. The React app keeps `/record`, `/auth`, `/dashboard`, `/admin`, `/terms` and `/privacy`.

**Tech Stack:** Cloudflare Workers (string-built HTML), React 18 + react-router 6, Tailwind 3.4, Vite 5, `node --test` (Node 24).

**Spec:** `docs/superpowers/specs/2026-10-05-one-site-design.md`

## Global Constraints

- Branch: `one-site` (already created; the spec is committed there). Do not merge or deploy; the owner deploys.
- Workers free plan, 10ms CPU per request: pages stay plain string builders, and the new pages do no D1 reads.
- Every value from a feed or query string goes through `escapeHtml` in Worker HTML.
- Public numbers are core edges only. The new pages cite **no** record figures.
- Do not touch `src/pages/Terms.jsx` or `src/pages/Privacy.jsx` content.
- Many files use CRLF line endings. Use the Edit tool for multi-line changes, not sed or a Node string replace.
- Commit messages are sentence case with no `feat:` prefix (match `git log`), and end with the attribution line shown in each commit step (or your own attribution line if you are not Claude).
- Test command: `npm test` (runs `node --test "worker/**/*.test.js"`; 209 tests pass at the start).
- Colors: gold `#d4a72e` (sharp-500); gradient `#f3dd8f → #c6971f → #8a6a17`, hover `#f7e6a8 → #d4a72e → #9c7818`; button text `#171717`. No `#10b981` or `#34d399` anywhere in Worker page output.
